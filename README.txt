ชุดเว็บไซต์แผนที่นำทาง 9 สถานที่ จังหวัดพิจิตร

ไฟล์:
- index.html หน้าเว็บแสดงภาพและปุ่มนำทางครบ 9 สถานที่
- map.png ภาพหลักตามที่ผู้ใช้ส่งมา
- make_qr.py โปรแกรมสร้าง QR Code เมื่อทราบ URL เว็บไซต์จริง

การเปิดใช้กับ LINE:
1. อัปโหลด index.html และ map.png ไปยังเว็บไซต์ที่เปิดผ่าน HTTPS ได้ (เช่น GitHub Pages, Netlify หรือเว็บของหน่วยงาน)
2. ทดสอบ URL ของหน้าเว็บจากมือถือและเบราว์เซอร์ภายใน LINE
3. สร้าง QR Code โดยรัน python make_qr.py https://URL-เว็บไซต์จริง/
4. สแกน QR Code ทดสอบว่าเปิดภาพหลักและกดปุ่มทั้ง 9 ได้

หมายเหตุ: QR Code ยังสร้างเป็นตัวใช้งานจริงไม่ได้จนกว่าจะมี URL สาธารณะ
ระยะทาง/เวลาและ QR Code ที่พิมพ์อยู่ในภาพหลักเดิมเป็นส่วนหนึ่งของภาพ ไม่ใช่ QR Code ที่ได้รับการตรวจสอบแล้ว
ควรแก้ไขภาพหลักก่อนเผยแพร่เป็นทางการ หากต้องการรับรองความถูกต้องของระยะทาง เวลา และ QR Code ภายในภาพ
